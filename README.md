# 1x1 Trainer

🚀 1x1 Turbo-Trainer: Ein moderner Multiplikationstrainer für schnelle, motivierende Kopfrechen-Übungen im kleinen Einmaleins (2-9).

- Moderne, mobilefreundliche Oberfläche  
- Schnelles spielbasiertes Training mit Highscore  
- Kein Tracking, keine externen Abhängigkeiten  
- Komplett im Browser, keine Installation nötig

## Live-Demo

Einfach die `index.html` öffnen und loslegen!
